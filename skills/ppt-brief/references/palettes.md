# 色板与默认约束库

用户答不上来时，从这里挑候选。**每套色板都配齐了完整的 6 项默认值——整组一起给，不要只给色板。**

使用方式：按场景挑 2–4 套 → 用 `AskUserQuestion` 呈现（选项里带 hex 值）→ 用户选定后整组采用。
若用户选了某套色板但想改质感词，允许局部替换。

---

## 场景 A · 学术答辩

**适用**：开题报告、组会汇报、中期检查、毕业答辩、课程展示

| 项 | 值 |
| :-- | :-- |
| 色板 | `#FFFFFF` / `#2563EB` / `#0EA5E9` / `#1E293B` |
| 质感关键词 | 严谨、清晰、证据驱动、留白充足、克制 |
| 元素清单 | 公式块、数据图表、示意图、参考文献标注、章节编号 |
| 负向约束 | 不要装饰性大图铺底；不要渐变标题栏；不要每页放图标卡片组；不要花哨动画感；不要超过 4 种颜色 |

**为什么这套配这组**：学术场景的读者在看"结论是否可信"，不在看"设计是否漂亮"。白底 + 深蓝最便于放公式和图，`#0EA5E9` 只用于强调关键数据。留白充足反而显得有底气。

## 场景 B · 科研数据

**适用**：论文图表汇报、数据分析报告、模型结果展示、技术方案评审

| 项 | 值 |
| :-- | :-- |
| 色板 | `#0F172A`（深底） / `#38BDF8` / `#34D399` / `#F8FAFC` |
| 质感关键词 | 冷峻、精密、数据密集、科技感、高对比 |
| 元素清单 | 折线/散点图、热力图、指标卡、误差棒、代码块或伪代码 |
| 负向约束 | 不要用浅色底（图表靠深底才跳得出来）；不要 3D 图表；不要饼图凑页数；不要卡通图标；不要彩色标题字 |

**为什么这套配这组**：数据可视化的第一要求是对比度。深底让亮色线条和热力图有最大辨识度。`#34D399` 做第二系列色，与 `#38BDF8` 色相差足够，色盲友好度较高。

## 场景 C · 品牌商业

**适用**：品牌分析、项目提案、营销方案、产品发布、商业计划书

| 项 | 值 |
| :-- | :-- |
| 色板 | `#F7F3EE`（奶油白） / `#F4A8C4`（泡泡粉） / `#E94752`（亮红） / `#64C9D4`（湖水蓝） |
| 质感关键词 | 年轻、有质感、有收藏感、展览册、不幼稚 |
| 元素清单 | 大幅产品图、圆角卡片、贴纸标签、矩阵图、数据条 |
| 负向约束 | 不要统一背景；不要每页三张等宽卡片；不要蓝紫科技渐变；不要把产品图缩成角落小图标 |

**为什么这套配这组**：暖调奶油白比纯白更"有温度"，适合消费类品牌。粉 + 红 + 蓝三色能做视觉分区，且亮红只用于焦点数据，不会满屏。**注意"不过度幼稚"这条很关键**——粉色容易滑向童趣，靠深色文字和大量留白压住。

## 场景 D · 气象科普

**适用**：科普分享、教学课件、公众讲座、社团宣讲

| 项 | 值 |
| :-- | :-- |
| 色板 | `#F0F7FA`（浅天蓝底） / `#2C7DA0`（深蓝） / `#F2C14E`（暖黄） / `#1D3557`（墨蓝） |
| 质感关键词 | 清透、亲切、有层次、科普感、信息友好 |
| 元素清单 | 卫星云图、环流示意图、剖面图、地图（须合规）、时间序列曲线 |
| 负向约束 | 不要用深色底（投影仪下看不清）；不要纯黑文字（用墨蓝更柔和）；不要堆砌术语不解释；不要红绿撞色配图 |

**为什么这套配这组**：气象主题天然适合蓝色系，浅蓝底在教室投影环境更安全。`#F2C14E` 暖黄作为唯一强调色，用来标"注意"类信息（如强对流、预警），与蓝色形成自然对比而非冲突。

**适用**：工作总结、述职报告、项目周报、团队介绍、培训课件

| 项 | 值 |
| :-- | :-- |

| 质感关键词 | 稳重、干练、结构化、不花哨、易读 |

**为什么这套配这组**：职场通用场景最安全的选择——中性灰蓝为主体，橙色只标重点。这套不出彩但绝不会出错，适合"内容重要、形式不需要抢戏"的场合。

## 通用负向约束库

用户想不出禁止什么时，从这里按场景挑 3–4 条给出来。**这几条是"AI 味"的最高发来源**：

| 约束 | 针对的 AI 味症状 |
| :-- | :-- |
| 不要统一背景 | 20 页同一张底图/同一个渐变，一眼模板 |
| 不要每页三张等宽卡片 | 最典型的"AI 排版"，所有内容都被切成三块 |
| 不要蓝紫科技渐变 | 通用默认审美，出现频率最高的"AI 色" |
| 不要标题居中 + 副标题居中的封面 | 最偷懒的封面公式 |
| 不要图标堆砌 | 用一堆填充图标撑版面，信息量其实为零 |
| 不要每页视觉重量相同 | 缺少 hero 页，翻页毫无起伏 |
| 不要把关键数字塞进图表角落 | 该做视觉锚点的数据被埋了 |
| 不要 200×70 的装饰小图 | 塞在标题栏右侧的无效配图 |
| 不要纯文字罗列 | 该配图的地方没配图 |

## 挑色板时的判断依据

不确定该推哪几套时，按这个顺序判断：

1. **用户身份/场景** → 学生做答辩走 A；科研汇报走 B；商业/品牌走 C；科普教学走 D；职场通用走 E
2. **投放环境** → 教室投影要浅底（A/D/E）；大屏或线上评审可深底（B）
3. **内容特征** → 数据图表多走 B；产品图片多走 C；公式示意图多走 A
4. **用户性格线索** → 说了"活泼/年轻"偏 C；说了"专业/严谨"偏 A；说了"别太花"偏 E

默认推 3 套即可（推荐 + 2 个备选），不要一次给 5 套让人挑花眼。第一套标注「推荐」。
