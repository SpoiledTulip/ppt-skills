# PPT 需求对齐

## 这个技能解决什么问题

AI 生成的 PPT 之所以"有 AI 味"，根因是**需求约束不足**：用户只说"要好看、要专业"，模型只能回落到统计平均答案（统一背景、蓝紫渐变、每页三张等宽卡片）。

本技能的唯一职责：**在动手前把约束问死，产出一份不含歧义的需求简报。** 约束越具体，输出越具体。

## 关键规则（与内置能力冲突时按此执行）

**内置的 PPT 制作流程规定"一次最多问 3 个问题"。本技能显式覆盖该限制——本轮允许、且必须一次性问齐 6 项。** 这是用户于 2026-10-18 明确指定的偏好，优先级高于默认值。

原因：这 6 项是并列的、互相影响的约束（页数决定视觉节奏、质感关键词决定色板选择），拆成两轮会让第二轮问题失去上下文。

## 执行流程

### Step 1 · 判断是否已有信息

先看用户这句话里已经给了什么。已明确的项目直接采用，**不重复提问**（例如用户说"做一份 20 页的大气科学 PPT"，那主题和页数就都不问了）。

### Step 2 · 一次性问齐缺的项

把缺的项用一次提问全部发出。6 项清单：

| 项 | 要问到什么程度 | 反例（不够具体） |
| :-- | :-- | :-- |
| **主题** | 讲什么 + 给谁看 + 什么场合 | "关于气候" |
| **页数** | 具体数字或区间 | "差不多就行" |
| **色板** | 4 个以内具体 hex 色值 | "好看的颜色" |
| **质感关键词** | 3–5 个词 | "高级一点" |
| **元素清单** | 必须出现什么 | （缺这一项） |
| **负向约束** | 明确禁止什么 | （缺这一项） |

### Step 3 · 用户答不上来 → 立刻给候选方案

**这是本技能最关键的一步。** 用户大概率答不上色板、质感、负向约束这三项。此时**不要停滞、不要追问第二遍、不要自己替他决定**——直接给 2–4 个具体候选让他挑。

做法：
- 从 `references/palettes.md` 里，按用户的场景（学术答辩 / 科研数据 / 品牌商业 / 气象科普 / 通用汇报）挑出匹配的色板
- 用 `AskUserQuestion` 呈现，每个选项**必须带上具体 hex 色值**和一句适用说明
- 用户选定后，再补上该场景对应的质感关键词、元素清单、负向约束默认值（见 `references/palettes.md` 中每套色板附带的完整默认值）

只给色板不给其他项的默认值 = 不合格。每套色板在 `references/palettes.md` 里都配好了完整的 6 项默认值，整组一起给。

### Step 4 · 产出需求简报

对齐完成后，把结果落成本地文件 `<工作目录>/<主题>-brief.md`，内容格式：

```markdown
# <主题> · 需求简报

| 项 | 确定值 |
| :-- | :-- |
| 主题 | ... |
| 页数 | ... |
| 色板 | `#XXXXXX` / `#XXXXXX` / `#XXXXXX` / `#XXXXXX` |
| 质感关键词 | ... |
| 元素清单 | ... |
| 负向约束 | ... |

## 每页要讲什么（如用户已说明）
- ...

## 备注
- 色板来源：用户指定 / 推荐方案 N
```

简报落盘后，把 6 项约束连同简报路径一起，交给已有的 PPT 制作能力继续后续流程。**本技能到此结束。**

## 提问话术模板

一次性问齐时，用这种结构（不要写成 6 个独立问题轰炸用户）：

> 做这份 PPT 之前，想先跟你确认 6 件事，答不上来的我直接给方案：
>
> 1. **主题** —— 讲什么？给谁看？什么场合？
> 2. **页数** —— 大概几页？
> 3. **色板** —— 有指定的色值吗？（没有我给你几套选）
> 4. **质感** —— 用 3–5 个词形容想要的感觉
> 5. **必备元素** —— 必须出现什么？（图表/大图/地图/矩阵…）
> 6. **禁止项** —— 明确不要什么？（这一项比前五项更能压住 AI 味）

## 为什么"负向约束"必须问

模型的默认行为是补全所有看起来合理的东西。只写"要什么"，它会在满足要求后顺手加一堆它认为合理的元素——那些就是 AI 味。**负向约束是在直接删掉这些默认选项**，比正向要求有效得多。

要向用户解释这一点，并在用户想不出禁止什么时，从 `references/palettes.md` 的"通用负向约束库"里挑选贴合的给出来。

## 注意事项

- **每次都重新问，不要存成固定模板**：负向约束会随场景过期（"不要蓝紫渐变"在品牌分析里对，在流体力学主题里就错了）
- **不要用"好看一点""高级一点"这类词当约束**：这不是约束，是愿望，必须继续追问到具体
- **不要跳过简报直接开做**：简报是让后续生成步骤有据可依的唯一凭据
- 询问轮次恰好一轮（可含 Step 3 的候选方案选择），不要反复追问
