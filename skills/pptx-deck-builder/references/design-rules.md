## 1. 为什么会有"AI 味"

根因不是模型审美差，而是**设计判断的密度太低**：

| 常见做法 | 后果 |
| :-- | :-- |
| 拿到主题 → 直接套模板 → 逐页填字 | 设计判断只发生 1 次，20 页共用同一套"判断" |
| 背景统一、版式重复、元素大小趋同 | 大脑瞬间识别为模板 |
| 只写"要什么"，不写"不要什么" | 模型补全所有它认为合理的元素，那些就是 AI 味 |

**解法**：把判断密度从"1 次"提到"每页 1 次"。每页都问自己：这页的角色是什么？视觉锚点在哪里？和上一页有什么不同？

## 2. 母版三区（已内建）

画布 1280×720，左右安全边距 64px。

| 区 | 垂直位置 | 高度 | 内容 |
| :-- | :-- | :-- | :-- |
| **A · 标题块** | 24–124 | 100px | 主标题 34px bold + 左侧 6×34px 竖条 + 右上章节贴纸 |
| **B · 内容区** | 124–656 | 532px | 所有正文、图表、配图、卡片 |
| **C · 页脚** | 656–696 | 40px | 左侧项目名 + 右侧页码 `NN / TOTAL` |

`header()` 一次性画出 A 区和 C 区。**内容页务必调用它**——母版一致是"专业感"的来源，而视觉节奏的差异靠 B 区内部实现。

封面 / 章节扉页 / 结束页可省略 C 区，用自定义版式（`cover()` 和 `section()` 已处理）。

## 3. 视觉节奏：hero / supporting / transition

20 页左右的一份 PPT，按这个比例分配角色：

| 角色 | 占比 | 视觉特征 | 强调色上限 |
| :-- | :-- | :-- | :-- |
| **hero** | 20–30% | 巨型数字 76–104px / 大图占 B 区 ≥40% | 18% |
| **supporting** | 60–70% | 信息密度高，颜色克制 | 6% |
| **transition** | 章节数 | 巨型章节数字 + 一片色块，极简 | 10% |

**三条硬约束**：

1. hero 页**不能相邻**——两个 hero 之间至少隔 1 个 supporting
2. 连续 ≥3 页同为"低信息量 supporting"→ 必须插入 hero 或 transition 打破沉闷
3. 相邻两页**版式必须不同**（含非对称版式之间）

封面和结束页默认是 hero。

## 4. 色彩纪律

### 装饰性几何图形是 AI 感的最大来源

**AI 感不是「难看」，而是「可有可无」。**

最常见的 AI 生成封面/结束页/章节页公式：

```
深色底 + 一个半透明大圆 + 一条竖色块 + 白字
```

它不丑，但它和任何主题都无关。读者会下意识觉得"这页是套上去的"。

**判断标准**：把页面上的某个元素单独拿掉，如果信息量**没有减少**，那它就是装饰，应该删掉。

| 元素 | 承载信息？ | 处理 |
| :-- | :-- | :-- |
| 大号对比数字 | ✅ 有 | 保留 |
| 时间/长度对比条 | ✅ 有 | 保留 |
| 章节序号（描边大字） | ✅ 有（导航） | 保留 |
| 半透明装饰圆 | ❌ 无 | **删** |
| 孤立小圆点 | ❌ 无 | **删** |
| 与内容无关的色块 | ❌ 无 | **删** |
| 装饰性细线（不分割内容） | ❌ 无 | **删** |

**更好的做法：用信息替代装饰。** 与其在结束页放一个装饰圆，不如放一张"台风 24 小时 vs 残涡 5 天"的时间对比条——它同时解决版面空洞和论证收尾两件事。

### 面积分配

| 角色 | 占比 | 用途 |
| :-- | :-- | :-- |
| 主色（背景） | 55–70% | 页面底、卡片面、留白 |
| 辅色 | 12–25% | 卡片面、分区、图表第二系列 |
| 强调色 | 6–12%（hero 可到 18%） | **只出现在焦点元素上** |
| 中性色 | 剩余 | 文本、描边、页脚 |

**关键**：统一的是**调色盘**（就 4 个色值），不统一的是**每页各色占多少面积**。至少 3 页的强调色占比要显著高于其余页。

### 禁忌

- 同一页出现 ≥2 套主色板
- 高饱和撞色铺满 ≥1/3 页面
- 全篇每页色彩比例雷同（差异 <10%）
- 两个强调色大面积直接相邻（需用背景色或辅色间隔）

## 5. 字号阶梯

| 层级 | 字号 | 字重 | 行高 | 用途 |
| :-- | :-- | :-- | :-- | :-- |
| 封面主标题 | 76–82 | bold | 1.12 | 仅封面 |
| 章节大字 | 68 | bold | 1.12 | 章节扉页 |
| **巨型锚点数字** | **76–104** | bold | 0.9 | 核心数据 |
| 页面主标题 | 34 | bold | 1.3 | 每页 A 区固定 |
| 卡片小标题 | 17–24 | bold | 1.4 | 卡片头 |
| 正文 | 19 | regular | 1.5–1.6 | 段落 |
| 数据标签 | 14 | bold | — | 数据条 |
| 脚注 / 页码 | 12–13 | regular | 1.4 | C 区 |

**关键规则**：巨型数字必须用**与正文不同的字体**（`num_font`，如 Arial Black），形成博物馆"标注卡"式的对比。全篇只用一套字体 = 缺少层次。

## 6. 版式清单与选择规则

### 对称版式（全篇最多 2 页）

| 版式 | 适用 |
| :-- | :-- |
| 全屏视觉 + 大标题 | 封面、章节扉页 |
| N 卡片横排 | 并列概念（⚠️ **全篇最多 2 页**） |
| 图表 + 洞察 | 数据分析 |
| 居中金句 | 核心观点 |
| 上下分栏 | before/after |

### 非对称版式（应占 ≥40%）

| 版式 | 典型结构 |
| :-- | :-- |
| 左大图 + 右侧文字 | 图占 52–62% |
| 非对称双栏 | 宽窄比 55:45 / 60:40 / 62:38 |
| 巨型数字 + 洞察 | ≥48px 锚点数字占视觉重心 |
| 上大图 + 下方卡片 | 图占上半 54–58% |
| 左标题 + 右内容 | 左色块栏 34% + 右内容 66% |

### 选择规则

- 相邻页不得用同一版式
- 连续 ≥2 页对称版式 → 第 2 页必须改非对称
- hero 页**禁止**使用 N 卡片横排
- 「左大图+右侧文字」与「非对称双栏」合计 ≤ 全篇 40%（避免另类单调）

### 内容类型 → 版式匹配

| 内容 | 最佳版式 | 避免 |
| :-- | :-- | :-- |
| 核心数据 / KPI | 巨型数字 + 洞察 | N 卡片横排（数据装进等宽卡片） |
| 产品 / 场景展示 | 左大图+右侧文字 | 50:50 等分双栏 |
| 观点 / 金句 | 居中巨型文字 | 装进引言卡片 |
| 对比论述 | 非对称双栏 | 上下等分栏 |
| 流程 / 架构 | 非对称版式 | N 卡片横排 |
| 数据密集列表 | 左标题 + 右内容 | 等宽四卡 |
| 人物/空间/产品等具象场景 | 左大图+右侧文字 | 用几何图形代替实拍图 |

## 7. 数据必须落点

**这是最容易被忽略、但对"专业感"影响最大的一条。**

关键数值后必须补一句判断，三选一：

- **含义解释**：这个数字说明处于什么状态
- **业务影响**：对决策意味着什么
- **管理启示**：据此该做什么

| ❌ 信息板（AI 味） | ✅ 汇报稿 |
| :-- | :-- |
| 2025 年海外收入 162.68 亿元 | 海外收入 162.68 亿元——一年内从"补充项"变成"半壁江山"，但增速的绝对值来自低基数 |
| 会员数 7258 万 | 会员 7258 万、贡献 93.7% 销售额——但真正建立情感认同的忠实粉仅约 22% |
| 营收增长 184.7% | 营收 371.2 亿元（+184.7%）——增速远超行业，同时把对单一 IP 的依赖推到了 38% |

**判断标准**：把这句话单独拎出来，如果读者只能知道"一个数字"，就是信息板；如果读者能知道"这意味着什么"，才是汇报稿。

## 8. 配色方案库

对应 `Palette` 的五个 classmethod。

### academic · 学术答辩

`#FFFFFF` / `#2563EB` / `#0EA5E9` / `#1E293B`

开题、组会、中期、答辩。白底便于放公式与图表，深蓝为骨架，`#0EA5E9` 仅标关键数据。**留白充足反而显得有底气。**

配套：质感词「严谨、清晰、证据驱动、克制」；元素「公式块、数据图表、示意图、参考文献标注」；禁止「装饰性大图铺底、渐变标题栏、每页图标卡片组、超过 4 种颜色」。

### research · 科研数据

`#0F172A` / `#38BDF8` / `#34D399` / `#F8FAFC`

论文图表、数据分析、模型结果。**深底是数据可视化的第一要求**——亮色线条和热力图在深底上对比度最大。`#34D399` 做第二系列，与 `#38BDF8` 色相差足够。

配套：质感词「冷峻、精密、数据密集、高对比」；元素「折线/散点图、热力图、指标卡、误差棒」；禁止「浅色底、3D 图表、饼图凑页数、彩色标题字」。

### cream_pink · 品牌商业

`#F7F3EE` / `#F4A8C4` / `#E94752` / `#64C9D4`

品牌分析、提案、营销方案、产品发布。奶油白比纯白更有温度，适合消费类品牌。亮红只用于焦点数据。

配套：质感词「年轻、有质感、收藏感、展览册、不幼稚」；元素「大幅产品图、圆角卡片、贴纸标签、矩阵图」；禁止「统一背景、每页三张等宽卡片、蓝紫科技渐变、产品图缩成小图标」。

### weather · 气象科普

`#F0F7FA` / `#2C7DA0` / `#F2C14E` / `#1D3557`

科普分享、教学课件、公众讲座。气象主题天然适合蓝色系，浅蓝底在教室投影环境安全。`#F2C14E` 暖黄作为唯一强调色，用于"注意"类信息。

配套：质感词「清透、亲切、有层次、信息友好」；元素「卫星云图、环流示意图、剖面图、地图、时间序列」；禁止「深色底（投影看不清）、纯黑文字、红绿撞色配图」。

> ⚠️ 地图元素须符合国家测绘合规要求（国界线、中国台湾、南海诸岛等按国家标准绘制）。

### business · 通用汇报

`#FAFAF9` / `#475569` / `#F97316` / `#0F172A`

工作总结、述职、周报、培训。中性灰蓝为主体，橙色只标重点。**不出彩但绝不会出错**，适合内容重要、形式不需抢戏的场合。

配套：质感词「稳重、干练、结构化、易读」；元素「进度条、时间轴、指标卡、对比表」；禁止「超过 3 种颜色、装饰性几何背景、每页标题栏雷同」。

### 挑色板的判断依据

1. **场景** → 答辩 A / 科研 B / 商业 C / 科普 D / 通用 E
2. **投放环境** → 投影要浅底（A/D/E）；大屏或线上可深底（B）
3. **内容特征** → 数据图表多走 B；产品图多走 C；公式示意图多走 A
4. **性格线索** → "活泼/年轻"偏 C；"专业/严谨"偏 A；"别太花"偏 E

## 9. 生成前自检清单

> **2026-10-22 实测补充**：以下几条是在真实生成 12 页后才发现的高频 bug，
> 全部已用 `on_color()` 在 API 层修复。若你自己写版式，务必逐条核对。

### 深色底必须换字色（最容易犯）

凡是深色填充（`accent3`、深色卡片、深色页），**文字色必须转白**。
渲染库已提供 `on_color(bg_hex)` 自动判亮度返回可读前景色：

```python
from deck_builder import on_color
color=on_color("#1E293B")   # → "#FFFFFF"
color=on_color("#F7F3EE")   # → "#1E1A17"
```

`header()` 的章节贴纸、`card(head_color=...)`、`cover(eyebrow=...)` 已自动调用。
**教训**：学术色板的 `accent3` 是深蓝 `#1E293B`，早期版本把贴纸文字写成 `self.p.text`（深色），
结果是黑底黑字——一整排页面都花了。

### 不许编造数据

学术/科研主题里，**任何数字都必须有出处**。实测时曾为了让版面好看，
给"水汽/抬升/持续"配了 92/78/86 的"相对权重"——那三个数没有来源，
属于严重错误，必须删掉，改用真实的物理阈值（如 `比湿 ≥ 12 g/kg`）。

**替代方案**：没有可信数字时，改用**巨型文字锚点**（如大号"3 个条件"）
或**定性对比**，不要造数。

### 等宽三卡横排：写进文档不等于有约束力

规范里写了"N 卡片横排全篇最多 2 页、hero 页禁止"，但实测时**自己写的 hero 页就用了三卡横排**。
原因：约束只在文档里，API 层没有任何拦截。

**对策**：写页面时主动检查——如果一页里出现 ≥3 个 `w` 相同的并排卡片，
把它改成「左锚点 + 右纵向列表」的非对称结构。

### 缓存陷阱

改完 `deck_builder.py` 后，若 `scripts/__pycache__` 还在，**运行时会加载旧代码**，
表现为"改了没生效"。每次改库后先清缓存：

```bash
rm -rf scripts/__pycache__
```

- [ ] **深色底上的文字已转白**（贴纸 / 深色卡片 / 深色页）
- [ ] **所有数字都有出处**，无编造
- [ ] 未出现 ≥3 个等宽卡片并排（除非确属并列概念，且全篇 ≤2 页）
- [ ] A/B/C 三区齐全，标题位置全篇一致
- [ ] 本页有 ≥1 个视觉锚点（≥48px 元素 或 占 B 区 ≥40% 的图）
- [ ] 与上一页版式不同；视觉重量有显著差异
- [ ] 强调色只出现在焦点元素上，面积不超过该角色上限
- [ ] 关键数字后有判断句（不是纯数据罗列）
- [ ] 留白 ≤35%（hero 页可到 45%，但须围绕焦点元素）
- [ ] 容器内内容填充率 ≥85%，尾部元素钉在容器底部
- [ ] 同行的多张卡片，其标题块/正文块/尾部在 y 轴上对齐（差 ≤16px）
- [ ] 全篇 hero 页占 20–30%，且互不相邻

### 全篇级检查

- [ ] 非对称版式 ≥40%
- [ ] 「左大图+右侧文字」+「非对称双栏」合计 ≤40%
- [ ] 至少 3 页的色彩比例与其他页显著不同
- [ ] 相邻两页版式两两不同
- [ ] 目录声明的章节数 = 章节扉页数
